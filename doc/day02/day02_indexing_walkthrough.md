# Day 2 补充：线性索引与二维映射逐步手算

这份补充材料只做一件事：把索引公式展开成可以拿纸笔推演的过程。第一次学习时，建议先手算，再运行程序。

## 1. 一维索引表

配置：

```text
blocks = 3
threads_per_block = 4
总线程数 = 3 × 4 = 12
```

完整映射：

| block | block 内线程 | 公式 | 全局线程编号 |
|---:|---:|---|---:|
| 0 | 0 | `0*4+0` | 0 |
| 0 | 1 | `0*4+1` | 1 |
| 0 | 2 | `0*4+2` | 2 |
| 0 | 3 | `0*4+3` | 3 |
| 1 | 0 | `1*4+0` | 4 |
| 1 | 1 | `1*4+1` | 5 |
| 1 | 2 | `1*4+2` | 6 |
| 1 | 3 | `1*4+3` | 7 |
| 2 | 0 | `2*4+0` | 8 |
| 2 | 1 | `2*4+1` | 9 |
| 2 | 2 | `2*4+2` | 10 |
| 2 | 3 | `2*4+3` | 11 |

可以观察到：block 决定编号所在的区间，thread 决定区间内的偏移。

## 2. 非整除输入的尾部线程

若 `n = 10`，只有下标 0～9 有效：

| 全局线程编号 | `index < n` | 行为 |
|---:|---|---|
| 0～9 | true | 执行加法 |
| 10～11 | false | 什么也不做 |

“什么也不做”不是浪费导致错误，而是 CUDA 中正常的尾部处理方式。错误的是让线程 10、11 继续访问数组。

## 3. Grid-Stride Loop 覆盖证明

配置：总线程数 6，`n = 14`。

每个线程的序列是：

```text
index = start + k × stride
stride = 6
k = 0, 1, 2, ...，直到 index >= n
```

展开后：

```text
start 0: 0, 6, 12
start 1: 1, 7, 13
start 2: 2, 8
start 3: 3, 9
start 4: 4, 10
start 5: 5, 11
```

把各行合起来恰好是 0～13。不会重复的原因是：两个不同 `start` 对 6 取余后的余数不同；不会遗漏的原因是：任何非负整数都能写成“商 × 6 + 余数”。

## 4. 二维 block 的坐标展开

配置：

```text
block = (2, 2)
grid  = (2, 2)
```

一个 block 有 4 个线程：

```text
threadIdx = (0,0) (1,0)
            (0,1) (1,1)
```

当 `blockIdx = (1, 0)` 时：

| `threadIdx` | `col = 1*2+x` | `row = 0*2+y` | 全局坐标 `(row,col)` |
|---|---:|---:|---|
| (0,0) | 2 | 0 | (0,2) |
| (1,0) | 3 | 0 | (0,3) |
| (0,1) | 2 | 1 | (1,2) |
| (1,1) | 3 | 1 | (1,3) |

## 5. 行主序地址展开

矩阵高 3、宽 4：

```text
逻辑矩阵                线性内存

(0,0) (0,1) (0,2) (0,3)   0  1  2  3
(1,0) (1,1) (1,2) (1,3)   4  5  6  7
(2,0) (2,1) (2,2) (2,3)   8  9 10 11
```

对 `(row=2, col=1)`：

```text
index = row * width + col
      = 2 * 4 + 1
      = 9
```

地址层面，如果 `float` 占 4 字节，那么相对数组起点的字节偏移是：

```text
9 * sizeof(float) = 9 * 4 = 36 bytes
```

代码中通常不手动乘 4，因为 `float*` 的 `pointer[9]` 已经按元素大小计算地址。

## 6. 典型错误定位

### 把高当成每行宽度

错误：

```cpp
index = row * height + col;
```

行主序中每跳过一行，跳过的是“一行包含的列数”，所以必须乘 `width`。

### 忘记 y 方向边界

错误：

```cpp
if (col < width) {
    output[row * width + col] = ...;
}
```

二维 grid 在最后一行也可能启动多余线程，因此必须同时检查 `row < height`。

### 用元素数量当字节数量

错误：

```cpp
cudaMemcpy(dst, src, n, cudaMemcpyHostToDevice);
```

第三个参数是字节数，应写成：

```cpp
const std::size_t bytes = static_cast<std::size_t>(n) * sizeof(float);
```

## 7. 纸笔练习

1. `blockDim.x=8`、`blockIdx.x=5`、`threadIdx.x=6`，求全局编号。
2. `n=65`、block size 为 32，求 block 数和多余线程数。
3. grid-stride 总线程数为 10，`start=7`、`n=35`，列出该线程的全部下标。
4. 矩阵宽 9，求 `(4,7)` 的线性下标。
5. 矩阵宽 9，线性下标 43 对应什么坐标？

答案：46；3 个 block、多 31 个线程；7、17、27；43；`(4,7)`。
